## Real bugs found and fixed (not just polish)
- **Crash**: a library-search focus hack looped with Android re-granting focus, causing a StackOverflowError on launch or return.
- **Lasso button bar placed against a sliver**: `RectF.isEmpty` is true for a single point, so the selection rect reset at every
  corner. The bar sat on top of the selection and off-centre. **Graphite has the same bug** (not touched).
- **New-notebook dialog**: the keyboard never hid, because the focus manager was read outside the dialog's own window.
- **Wheel gesture reset** (above).
- **Toolbar centring**: a saved drop position (along = 0.38) silently pulled the toolbar left.

7. **Later rounds (all QA-passed and pushed, last c903ad7):** rails don't trigger system Back, deliberate pull-to-add
   (hold 350 ms; fast swipes in class no longer add pages), highlighter shows as active, corner docking lands where
   dropped, no layout jumps, export preview uses the notebook's paper, accessibility pass (screen-reader labels/roles,
   no clipping at 1.3× font, Android's Remove-animations honoured), rotation keeps your zoom / stays fitted, Back
   clears a lasso selection first.

## Pen speed (S9, gfxinfo)
- **Writing, controlled A/B** (same 10 strokes, 3 runs each): final build p99 15–19 ms vs the before-review build 18–22 ms,
  so no regression (slightly better). Live ink is front-buffered and unaffected; the slow frame is the committed-stroke
  redraw at pen-up, worth a profiling pass later. (An earlier "p99 8 ms" counted many cheap animation frames; not comparable.)
- **Pen switching**: p99 14 ms.
